내 빗썸 계좌 연결

  1. 자산 조회용 API 키 발급

    빗썸 API 관리 ↗에서 자산·주문·입출금 조회 권한과 허용 IP를 설정하세요.

  2. 키를 이 컴퓨터에 저장

    터미널에서 아래 명령을 실행하면 입력한 키가 화면에 보이지 않고 이 컴퓨터에만 저장됩니다. .env 파일은 --env-file .env로 지정합니다. 키를 채팅창에 붙여넣지 마세요.

    node cli/asset-kit.js config init
node cli/asset-kit.js doctor
  3. 내 계좌로 실행

    데모(npm run demo)를 종료한 뒤 프로젝트 폴더에서 실행하세요.

    npm start

이 데이터로 나만의 대시보드 만들기

npm run demo

화면 편집에서 위젯·순서·자산 범위·기간을 바꾸거나, 화면 파일을 고쳐 node cli/asset-kit.js dashboard --web-dir 폴더로 띄울 수 있습니다.

대화 속 대시보드잔고·손익비중·추이일별 변화시세·시장 개요경보·거래 유의주문·입출금종합 보고서화면 설정화면 템플릿

API 키는 브라우저로 보내지 않고 자산 데이터만 전달합니다. MCP를 사용하면 조회 결과가 연결한 AI 서비스에 전달될 수 있습니다. 자산 추이는 조회할 때마다(최대 5분에 한 번) 이 컴퓨터에 기록됩니다.
