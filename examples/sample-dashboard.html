내 빗썸 계좌 연결

  1. 자산 조회용 API 키 발급

    빗썸 API 관리 ↗에서 자산·주문·입출금 조회 권한과 허용 IP를 설정하세요.

  2. 키를 이 컴퓨터에 저장

    터미널에서 아래 명령을 실행하면 입력한 키가 화면에 보이지 않고 이 컴퓨터에만 저장됩니다. .env 파일을 써도 됩니다. 키를 채팅창에 붙여넣지 마세요.

    node cli/asset-kit.js config init
node cli/asset-kit.js doctor
  3. 실제 자산 모드로 실행

    데모 실행을 종료한 뒤 프로젝트 폴더에서 실행하세요.

    npm start

이 데이터로 나만의 대시보드

npm run demo

화면 편집에서 위젯·순서·자산 범위·기간을 바꾸거나, 화면 파일을 고쳐 asset-kit dashboard --web-dir 폴더로 띄울 수 있습니다.
